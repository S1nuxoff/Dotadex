# Dotadex tasks

Goals for the site (`dota2-model-viewer`) and the dataset export (`dota2-model-tracker`).

Status: `[ ]` open · `[~]` in progress · `[x]` done · `[-]` cancelled (with the reason).
Every task has an ID. Done and cancelled tasks move to the archive at the bottom; nothing is deleted.
Each open task also has a GitHub issue (its number after the ID); new bugs and ideas can start there. A fix closes its issue with `Fixes #N` in the commit.

Order: cosmetics first (every particle and effect as in the game), abilities as in a match later.

---

## Particles: data (export, `dota2-model-tracker/particles.js`)

- [x] **P-11 Sheet frames squeezed to the first one's size.** `buildTexture` laid a sheet's frames in a grid of cells the first frame's size; frames differ within a sheet, so Ember Spirit's fire (`fire_particle_10_low`, a first frame of 15x22, flames up to 103x110) came out 5 to 7 times smaller and blurry; 145 of the 174 sheets have frames of different sizes. Frames are now packed at their own sizes, 2 pixels apart (commit `1d85d24` in dota2-model-tracker, `TEXTURE_VERSION` 2 builds all 731 textures again once). Uploaded 2026-10-18. Then: the game draws each frame's whole cell (`uvUncropped`, e.g. 128x128 with clear space round), the picture at its place in it (`uvCropped`); Source2Viewer exports the cropped picture alone, which was stretched over the whole sprite, so frames jumped in size and place (the fire choppy and blurry). The cells are read from the textures' DATA print and each frame put in its cell (`TEXTURE_VERSION` 3, all textures built again once). Uploaded 2026-10-18; checked on the site (Ember Spirit's fire as in the game).
- [~] **P-12 (#1) Particle defaults from the engine's schema dump.** A `.vpcf` writes only fields that differ from the default, so every field the site reads needs the engine's default; they were hand-written fallbacks (~400 `??` in `src/viewer/particles/`), some guessed from the data. Source found 2026-10-22: [DotaFlow/dota2_client_dump](https://github.com/DotaFlow/dota2_client_dump) (bot dump of the client after every game update), `sdk/include/source2sdk/schemas/`: the SchemaSystem dump, every class with its fields and defaults (`// = ...`).
